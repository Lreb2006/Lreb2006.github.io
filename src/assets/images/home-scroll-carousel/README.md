# 首页滚动轮播图片

把需要出现在电脑端首页中间轮播层的图片放在这个文件夹。

## 排序

文件名前面的数字决定顺序，建议每次间隔 10：

```text
010-first.jpg
020-second.png
030-third.webp
```

以后如果要在第一张和第二张之间插图，可以命名为：

```text
015-new-image.jpg
```

没有数字前缀的图片会排在所有编号图片后面，再按文件名排序。

支持 `.jpg`、`.jpeg`、`.png`、`.webp` 和 `.avif`。添加、删除或重命名图片后需要重新构建并部署网站。
